# Brightline – Business & Digital Solutions Website

Brightline is a modern, responsive, and user-friendly business website designed to provide digital solutions for growing businesses.

The website presents Brightline's services, products, projects, testimonials, FAQs, and contact information through a clean and professional interface.

## 🚀 Features

- Modern and responsive design
- User-friendly navigation
- Light/Dark mode
- Responsive mobile layout
- Hero section with call-to-action buttons
- Services showcase
- Product pricing plans
- Project portfolio
- Client testimonials
- FAQ section
- Contact form
- Interactive UI elements
- Smooth animations and transitions
- Mobile-friendly design

## 🌐 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/brightline-business.git
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the website

Open `index.html` in your browser.

For a better development experience, use the **Live Server** extension in VS Code.
